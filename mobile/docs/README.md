# Pasta `docs/`

Coloque aqui os **screenshots e materiais visuais** do app.

## Como adicionar uma foto

1. Tire um print do app no celular (recomendado: tela inicial com dados reais)
2. Salve com um nome descritivo, ex: `screenshot-home.png`, `screenshot-cofrinhos.png`
3. Faça commit: `git add docs/ && git commit -m "docs: add home screenshot"`
4. A imagem aparece automaticamente no `README.md` da raiz do mobile

## Sugestões de screenshots

- `screenshot-home.png` — Home com cards de resumo
- `screenshot-cofrinhos.png` — Tela de metas com Aportar/Resgatar
- `screenshot-irpf.png` — IRPF com progresso
- `screenshot-export.png` — Tela de export CSV/PDF

## Formato recomendado

- **Largura:** 1080px (ou proporção similar)
- **Formato:** PNG (com perda) ou JPG
- **Tamanho:** < 500KB cada pra não pesar o repo
