feat(bg): ShapeGrid global em Skia (verde-limao do kit)

Adiciona background animado global atras de todas as telas,
usando porta em react-native-skia do componente ShapeGrid do React Bits.

COMPONENTE (src/components/ShapeGrid.tsx)
- Canvas Skia 60fps com malha de linhas (verticais + horizontais)
- Cor das linhas: verde-limao do tema (colors.hero) com opacidade 0.18
- Animacao diagonal lenta via useSharedValue + withRepeat(withTiming)
- Vignette radial sutil no centro para nao competir com o conteudo
- pointerEvents="none" -> toques atravessam para o conteudo
- Respeita light/dark (vignette branca no light, preta no dark)
- Props configuraveis: squareSize, speed, borderOpacity, vignetteRadius

PLUGUE NO ROOT (app/_layout.tsx)
- ShapeGrid e o PRIMEIRO filho do View raiz, garantindo que fica
  atras de tudo via empilhamento natural (depois vem navigator/header)
- contentStyle do Stack agora transparente para nao esconder o grid

TELAS AJUSTADAS
- root backgroundColor de 6 telas -> 'transparent':
  * Home, Contas, Orcamento, Assinaturas, IRPF, Export
- 4 telas legadas (loans, goals, simulacoes, settings) mesmo ajuste
- Tab bar: bg opaco -> rgba(0,0,0,0.85) (deixa grid aparecer atras,
  mas mantem contraste dos itens)

DEPENDENCIAS
- @shopify/react-native-skia@1.9.1 adicionada (~5 pacotes)
- Versao 0.5.0 -> 0.6.0

ATENCAO SOBRE EXPO GO
- Skia e modulo NATIVO. Em Expo Go puro, nao vai funcionar
  (vai lancar "Cannot find native module").
- Para rodar e necessario:
  1) `npx expo prebuild --clean --platform android`
  2) Rebuild do APK ou `eas build --profile development`
  3) Instalar o development build no Android
- Alternativa se preferir: substituir por View+Reanimated (sem Skia)
