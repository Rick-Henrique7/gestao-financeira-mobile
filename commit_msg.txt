fix(bg): ShapeGrid reescrito em Reanimated (sem Skia)

Skia 1.x quebra com React 19 / RN 0.83:
- 1.9.1: 'Cannot access play before initialization' (TDZ)
- 1.5.7: 'Cannot read properties of undefined (reading ReactCurrentOwner)'

Skia 1.x oficialmente suporta ate RN 0.75. Skia 2.x (que suporta RN 0.83)
ainda nao foi lancado. Reverter para Reanimated puro.

MUDANCAS
- Removido @shopify/react-native-skia (desinstalado)
- src/components/ShapeGrid.tsx: reescrito com View + transform animado
  - Linhas verticais/horizontais: <View> 1px com backgroundColor hero+alpha
  - Movimento diagonal: useSharedValue + withRepeat(withTiming, -1)
  - Vinhette: View absoluto com borderRadius alto + opacity (dark=black,
    light=white) - nao fica perfeito como Skia, mas quebra o galho
  - Reanimated 4: Animated.View via import default
- package.json version 0.6.1 -> 0.6.2
